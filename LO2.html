Reflectie

Ik gebruik de codeertalen: HTML, CSS en Javascript, om interactieve media producten te maken zoals de portfolio website waarop je dit leest. Ik doe onderzoek naar de codeertalen; ik gebruik verschillende hulpbronnen om mijn vaardigheden verder te ontwikkelen. Ook maak ik oefenopdrachten die behandeld worden tijdens workshops, en documenteer deze.

Ik heb websites live gezet, waarbij ik verschillende manieren heb onderzocht; ik heb zowel de HERA server van Fontys als een externe host (dash.cloudflare.com) met eigen domein gebruikt.

Om mijn codeerproces bij te houden en op te slaan, maak ik gebruik van Github (voor mijn portfolio) en Gitlab (voor projecten en oefeningen). Ook heb ik een README file toegevoegd aan mijn portfolio folder, die te zien is in mijn Github repository. Klik op onderstaande logo's om een kijkje te nemen.
